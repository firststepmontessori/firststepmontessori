# Calm Prepared Garden theme

- Status: Approved and implemented
- Audience: School approver, designers and frontend developers
- Owner: Theme maintainer
- Last updated: 2026-08-30

## Character

Garden presents First Step as calm, tactile and carefully prepared. It combines warm paper-like space, forest typography, muted sage forms, terracotta blocks and small marigold moments. The layout is editorial but practical, never rustic or ornamental for its own sake.

## Layout language

The hero pairs an approximately 55% copy column with a large abstract garden composition. Subsequent sections alternate canvas and surface backgrounds with generous whitespace. Programme cards remain ordered and equal-height on desktop, two-up on tablet and single-column on mobile.

## Motifs and motion

Botanical line paths draw once while blocks settle by eight pixels or less. Animation is 240–420ms except the one-time hero line drawing. No headline or call-to-action waits for motion.
