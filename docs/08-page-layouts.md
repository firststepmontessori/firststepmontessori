# Page layouts

- Status: Public and journal layouts implemented
- Audience: Designers, content owners, developers and QA
- Owner: Design-system maintainer
- Last updated: 2026-08-31

## Shared frame

Desktop uses a sticky compact header, a 74rem shell, generous section spacing and a three-column footer. Below 46rem, principal layouts become one column, navigation uses a native disclosure control and copy precedes decoration. The saved concept boards are compressed showcases, not spacing templates.
