# Brand design system

- Status: Implemented baseline; final logo approval pending
- Audience: School approver, designers and frontend developers
- Owner: Design-system maintainer
- Last updated: 2026-08-30

## Shared identity

Both themes use the same code-native mark: four ordered forms suggesting a first step, a leaf and Montessori learning geometry. It is intentionally redrawn rather than embedding the flyer raster. A formal trace of the flyer logo remains deferred until the school confirms that the flyer mark is the intended long-term identity.

## Typography

Atkinson Hyperlegible is the shared body/UI family. Garden uses Fraunces for headings; Geometry uses Nunito Sans. Headings use sentence case, balanced wrapping and restrained tracking. Body copy stays near 65–75 characters per line.

## Scale and spacing

The page shell is capped at 74rem, with 80–136px responsive major-section spacing on desktop and about 72px on mobile. Cards use 12–28px radii depending on theme. Controls have at least a 44px interactive size, and the mobile mode buttons exceed that target.

## Components

Shared components include header, logo, mode controller, buttons, page hero, programme cards, feature cards, rhythm steps, location/contact CTA and footer. Theme differences are token and decorative-shape changes; information, semantics and interaction remain identical.

## Illustration rules

Only original inline SVG and CSS shapes are shipped. Garden uses leaves, stems, arches and settling blocks. Geometry uses circles, arches, half-moons, squares and stepped structures. Illustrations carry meaningful alt labels when they communicate a scene and are hidden when decorative.

## Accessibility

Tokens must meet WCAG 2.2 AA in both colour modes. Information never relies on colour alone. Focus rings use a visible three-pixel accent. Motion is an enhancement, public content remains readable before animation, and reduced-motion preferences are respected.
